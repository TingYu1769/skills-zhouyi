## PDF 模式（2026-10-19）

环境：Python 3.13.13、PyMuPDF 1.28.2、Pillow 12.3.0，通过 `uv` 的隔离环境运行。

### 工具与技能结构

以下命令通过，当时合计 **20 项功能测试**：

```bash
uv run --with 'pymupdf>=1.26,<2' --with 'pillow>=11,<13' python -m unittest discover -s evals -p 'test_*.py' -v
```

测试覆盖普通页、旋转页和扫描页的原页渲染与像素裁剪，跨页表格及底部注释，源 PDF 一致性与恢复，重裁后的复核状态，无效页码和区域、损坏 PDF、图片缺失或损坏，Markdown 结构和图片路径，交付校验、ZIP 打包及目录迁移。技能入口通过 `skill-creator` 的结构校验。

测试中的模拟复核记录用于验证状态变化；实际内容与图片检查另见以下两个实验。

### Transformer 全文端到端验收

原文：[Attention Is All You Need，arXiv:1706.03762v7](https://arxiv.org/abs/1706.03762v7)，15 页。首次公开于 2017-06，输入版本为 v7。原 PDF SHA-256：

```text
bdfaa68d8984f0dc02beaca527b76f207d99b666d31d1da728ee0728182df697
```

#### 实测发现及修正

标准 Markdown 脚注语法 `[^4]`、`[^5]` 在实际渲染中被重新编号为 1、2。译稿改用明确的上标和对应编号说明，重新渲染后显示为 4、5；这一处理方法已补入翻译规范与验收说明。

表 2 首版截图顶部带入少量英文图注残边。调整裁剪上边界后重新打开，确认残边已排除，表头、各数据行和底边完整。

#### 原文差异

以下内容保持输入 PDF 的写法，记录在工作目录中：

- 英法翻译 BLEU 在摘要和表 2 中为 41.8，在正文 6.1 中为 41.0。
- 第 5.1 节给字节对编码标注的引用为 [3]。
- 第 5.4 节导语写“三种正则化”，随后有两个具名段落，分别讨论残差及嵌入处 dropout 和标签平滑。

这份 PDF 为单栏；双栏、扫描页、跨页表格、算法和提示词由虚构论文实验覆盖。本次是同一 agent 执行的一次完整真实论文验收。

## 源码模式（2026-10-22）

环境：Python 3.13.13、PyMuPDF 1.28.2、Pillow 12.3.0，TeX Live 2026（XeTeX），Noto CJK SC 与 AR PL UKai 字体。

### 功能测试

设置 `ZHOUYI_TEXBIN` 后运行功能测试，**44 项全部通过**（`test_preflight.py` 7 项、`test_tex.py` 20 项、`test_tools.py` 17 项），其中 6 项实际调用 XeLaTeX 编译。源码模式的测试覆盖：

- 解包、主文件识别和不安全路径；
- 字体行的注释与 `zh-setup.tex` 的插入，包括类文件里的字体行、合并后重新统计替换的字体，以及 `no-math` 写在 `\documentclass` 同一行、只多出一行；
- 编译日志摘要（错误、缺字、横向与纵向溢出）；
- 按节切块、超长的节在小节处再切、注释里的标题不作块标题、`\input` 带点的文件名；
- 占位符还原、手工修正的覆盖、未改动的块合并后与源码一致、丢失或新增占位符的块被拒收；
- 译文导致编译失败时只退回出错的块，源码本身编译失败时停下；
- 交付与 `tex-check`。

### 真实论文

开发期间在多篇使用不同模板的 arXiv 论文上完整跑过源码模式：先编出英文底稿并与原 PDF 逐页比对文字和字形，再逐块翻译、合并、编译、核对版面并交付。由此发现并修正的问题包括：模板为 pdfLaTeX 准备的数学字体在 XeLaTeX 下显示成错误字形而编译不报错，类文件和样式文件里的 Type 1 字体没有被替换，`latexmk` 的输出含非 UTF-8 字节时脚本退出。仍需人工处理的情形列在 [LaTeX 源码模式](../skills/zhouyi/references/latex-source.md)的“已知限制”里。

## 源码模式改进（0.2.0，2026-10-28）

### 功能测试

设置 `ZHOUYI_TEXBIN` 后运行功能测试，**59 项全部通过**（`test_preflight.py` 7 项、`test_tex.py` 35 项、`test_tools.py` 17 项），其中 8 项实际调用 XeLaTeX 编译。新增的 15 项覆盖：

- 逗号列表里的字体包、`--main`、交付带上 override 新增的文件、删掉的 override 恢复源码原样；
- 切块后改动 `W/src/` 时合并报错，主文件在子目录时找到 PDF，报错行未经翻译时停下而不退回，`--retry-reverted`；
- 论文自定义的 verbatim 环境的识别（包括注释里和 verbatim 正文里的假定义），verbatim 到第一个字面 `\end` 为止，行内 verbatim，`$` 跨空行报错，`verbatim_envs` 与 `kept_prose`；
- 注释里的 `\begin`，花括号与原文块比较、按反斜杠奇偶计数，不在花括号组里切开。

每处修改都做了变异检查：把代码改回旧逻辑，对应的新测试失败。

### 真实论文

这些修正来自一批 arXiv 论文源码模式翻译中暴露的问题。修正后，用新代码在 35 篇论文的源码上重新切块，与修正前比对：没有论文因新增的 `$` 检查报错；28 篇的块数和正文字符数不变；其余 7 篇的变化都来自行内 verbatim 或 listing 类的提示词框，这些框现在整段保留，并列入 `kept_prose`。原文花括号组跨两块的 2 篇，组内的节并入了同一块，切出的块全部配平。
